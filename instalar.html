Instalá la app web para abrir ATMÓS desde el inicio del iPhone. Los widgets del sistema se configuran por separado con Scriptable.

Abrir ATMÓS ↗

01 · Instalá la app web

  1. Abrí ATMÓS en Safari, no dentro del visor de otra app.
  2. Tocá Compartir → Agregar a pantalla de inicio. Según tu versión de iOS puede estar dentro de «Más».
  3. Activá Abrir como app web si aparece esa opción y tocá Agregar.
  4. Abrí ATMÓS y consultá tu ciudad con Internet. La interfaz y ese pronóstico podrán consultarse sin conexión si el dispositivo conserva el almacenamiento.

Sin Internet no hay pronósticos nuevos. El caché conserva su fecha; no debe interpretarse como información actual. «Agregar a pantalla de inicio» requiere la acción del usuario.

02 · Agregá un widget

  1. Instalá Scriptable desde su sitio oficial/App Store.
  2. Descargá el script ATMOS-Widget.js. Abrilo como texto, copiá todo y creá un nuevo script en Scriptable llamado ATMOS-Widget.
  3. Ejecutalo una vez desde Scriptable con Internet. Utiliza Open-Meteo sin una clave privada.
  4. En la pantalla de inicio del iPhone, mantené pulsado → editar/agregar widget → Scriptable. Elegí el tamaño y seleccioná ATMOS-Widget en su configuración.
  5. En «Parámetro», pegá la ubicación. En ATMÓS: Ajustes → Widget de esta ciudad → Copiar. Ejemplo: -34.6037,-58.3816|Buenos Aires.

También incluye presentaciones para widgets de pantalla bloqueada cuando Scriptable y tu versión de iOS los admitan. La PWA y Scriptable no comparten almacenamiento; seleccioná la ciudad en ambos.

Las animaciones pertenecen a la interfaz de ATMÓS. El widget del sistema es una vista estática. iOS decide cuándo actualizarlo; no hay un intervalo de refresco garantizado.

03 · Movimiento a tu medida

En Ajustes → Motion graphics, elegí Auto o Reducido. Auto también respeta «Reducir movimiento» de iOS. Las animaciones ambientales se pausan cuando la escena sale de pantalla o la página deja de estar visible.

La escena depende del código meteorológico y del estado día/noche del modelo. Es una interpretación visual, no un radar, video en vivo ni medición de partículas.

Datos, privacidad y recuperación

ATMÓS envía la ciudad buscada a la API de geocodificación de Open-Meteo y las coordenadas elegidas a su API meteorológica. No incorpora publicidad, telemetría propia ni claves secretas. GitHub Pages y los proveedores externos pueden registrar solicitudes según sus políticas.

Guardá un respaldo desde Ajustes → Exportar respaldo. Restaurar un respaldo reemplaza datos locales sólo después de tu confirmación. «Compartir ubicación» incluye coordenadas en el enlace.

Los datos se atribuyen a Open-Meteo/GeoNames bajo CC BY 4.0. La API gratuita es para uso no comercial. Esta app no reemplaza los avisos meteorológicos oficiales.
